# Task-Manager
Created a Task-Manager using Rust. Created as a learning hobby project for enums & structs.

# How To Run

Clone the respository, find the main.rs file, compile it using this command: `rustc main.rs`.

If it fails, check if you have the Rust compiler installed.

After compiling, run this command:

#### Windows
`.\main`

#### macOS/Linux
`./main`

Have fun :)

Features:

- Interactive GUI
- Saving & Storing
- Viewing
